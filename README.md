# Сервис сокращения ссылок (LinkShortener)

Консольное Java-приложение для генерации коротких ссылок с поддержкой многопользовательских сессий (UUID), лимитов переходов, автоматического истечения срока действия (TTL) и фоновой очистки. Разработано на чистой Java с соблюдением принципов многослойной архитектуры без использования сторонних фреймворков.

## Основные возможности

* ****Уникальность ссылок:**** генерация коротких кодов в формате Base62 (`a-z`, `A-Z`, `0-9`). При сокращении одного и того же URL разными пользователями создаются уникальные короткие ссылки.  
* ****Лимит переходов:**** блокировка ссылки при исчерпании допустимого количества открытий с уведомлением пользователя.  
* ****Контроль времени жизни (TTL):**** автоматическая деактивация просроченных ссылок и их фоновое удаление через `ScheduledExecutorService`.  
* ****Идентификация и права доступа:**** привязка ссылок к `UUID` создателя. Редактировать лимит переходов или удалять ссылку может только её владелец.  
* ****Автоматический редирект:**** открытие оригинального URL в системном браузере через `java.awt.Desktop`.

## Архитектура проекта

Проект разделен на независимые слои с ручным внедрением зависимостей (Manual Dependency Injection) в точке входа `Main`:
```
LinkShortener/  
├── src/  
│   ├── config/  
│   │   └── AppConfig.java                # Загрузка настроек из config.properties  
│   ├── domain/  
│   │   ├── model/  
│   │   │   ├── ShortLink.java            # Доменная модель короткой ссылки  
│   │   │   └── User.java                 # Доменная модель пользователя  
│   │   └── exception/                    # Доменные исключения (TTL, лимиты, права доступа)  
│   ├── repository/  
│   │   ├── LinkRepository.java           # Интерфейс хранилища  
│   │   └── InMemoryLinkRepository.java   # Потокобезопасная реализация на ConcurrentHashMap  
│   ├── service/  
│   │   ├── LinkService.java              # Главная бизнес-логика и валидация  
│   │   ├── ShortenerService.java         # Генератор Base62 кодов (SecureRandom)  
│   │   ├── NotificationService.java      # Уведомления об истечении лимитов и TTL  
│   │   └── CleanupScheduler.java         # Фоновая служба автоочистки истекших ссылок  
│   ├── ui/  
│   │   └── ConsoleUi.java                # Интерактивный CLI-интерфейс  
│   ├── config.properties                 # Конфигурационный файл по умолчанию  
│   └── Main.java                         # Точка входа (Composition Root)  
└── test/  
    └── service/  
        └── LinkServiceTest.java          # Модульные тесты (JUnit 5)
```
## **Конфигурация (src/config.properties)**

Параметры по умолчанию задаются в файле config.properties (при отсутствии файла система использует встроенные резервные значения):

Properties  
app.default.ttl.hours=24  
app.default.click.limit=10  
app.cleanup.interval.seconds=60

## **Сборка и запуск**

### **Запуск в IntelliJ IDEA**

> 1. Откройте проект в IntelliJ IDEA.  
> 2. Запустите метод main в классе src/Main.java.

### **Запуск тестов**

Запустите класс test/service/LinkServiceTest.java через встроенный раннер JUnit 5 в IDE.

## **Использование CLI**

После запуска в консоли отображается текущий UUID пользователя и интерактивное меню:

* **1. Сократить ссылку** — введите длинный URL (http:// или https://). При желании укажите свой лимит кликов и TTL в часах (или нажмите Enter для применения настроек из config.properties).  
* **2. Перейти по короткой ссылке** — введите 6-значный код ссылки. Если ссылка активна, счётчик переходов увеличится, а URL откроется в браузере.  
* **3. Мои ссылки** — выводит список всех ссылок текущего пользователя со статистикой кликов и временем истечения.  
* **4. Изменить лимит переходов** — позволяет владельцу ссылки установить новое максимальное количество кликов.  
* **5. Удалить ссылку** — досрочное удаление ссылки её владельцем.  
* **6. Сменить пользователя** — нажмите Enter для генерации нового UUID или вставьте существующий UUID для переключения между аккаунтами и проверки разграничения прав доступа.  
* **0. Выход** — корректно останавливает фоновый поток очистки и завершает работу программы.
